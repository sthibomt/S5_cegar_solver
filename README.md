# S5_CEGAR_SOLVER
-----------------

# What is it?
-------------
SAT-Based_decision_procedures for S5 and multi-agent S5n.
CEGAR-Tableau based SAT solver optimized for S5 and extended to S5n.

# Usage:
--------
Navigate to the build folder and run the following commands:
cmake ..
make
./s5solver "<inputFormula>"
